# Shomen

型付きの文書サーバー型 Web フレームワーク（作業名）。

正本はチャットではなく、次のファイルである。

1. `docs/00-INSTRUCTION.md` — 仕様と受入条件
2. `docs/01-ARCHITECTURE.md` — 層とモジュール境界
3. `docs/02-PHASES.md` — 実装順
4. `docs/03-CONVENTIONS.md` — コード規約
5. `AGENTS.md` — エージェント共通ルール
6. `CLAUDE.md` — Claude Code 用の入口（中身は AGENTS.md を指す）

実装を始めるエージェントは `AGENTS.md` を読み、フェーズ 0 だけを行う。
