# 状況

仕様 3 は、同じビューに対応する `label`（`for` かラップ）か `aria-label` が無い `input` をコンパイル時に拒否するとしている。1 つのマクロ呼び出しからは、兄弟要素が見えない。

当初はメソッドごとに検査していた（`macro inherited` が各サブクラスに置く `macro method_added`）。最終レビューで次の点が見つかった。別のメソッドにある `label` を数えず、仕様の「同じビュー」より厳しい。ビューに include したモジュールのメソッドは検査されない。`self.input(...)` が検査から漏れる。`"aria-label": ""` が通る。`for:` と `id:` が文字列リテラルでないと照合されないのに、エラーがそれを言わない。`type: "submit"` の `input` に、ラベルを付けよという合わない助言を出す。

# 決定

`Shomen::View` の `macro finished` で、すべてのサブクラスを 1 つずつ検査する。検査の対象は、そのビュー自身、親のビュー、それらが include したモジュールのメソッドである。`Shomen::View` 自身とその祖先は含めない。メソッドごとに、展開前の本体を `stringify` して行単位で走査する。

`for:` の集め方はビュー全体で 1 つにする。`input(...)` と `self.input(...)` の呼び出しが次のいずれも満たさなければコンパイルエラーにする。

- ビューのどこかに `label(..., for: "x")` があり、`input` に文字列リテラルの `id: "x"` がある
- 同じメソッドの中で、`label ... do` ブロックの中にある。ブロックの範囲はインデントではなく、`do`、`if`、`unless`、`while`、`until`、`case`、`begin` と `end` を数えた入れ子の深さで決める
- 空でない `"aria-label": ` か `"aria-labelledby": ` を持つ。空文字列のリテラルは数えない
- `type: "hidden"` を持つ（ラベルが不要な要素なので検査しない）

文字列リテラルと正規表現リテラルの中身は、呼び出しの検出から外す。エラーは `input needs a label` を含み、`for:` と `id:` は文字列リテラルでなければならないことを書く。`type` が `submit`、`reset`、`button`、`image` の `input` には、`button` を使うよう書き足す。これらの `input` も検査の対象から外さない。

# 理由

`stringify` は `{ ... }` のブロックも `do ... end` で書き、文が 1 つのブロックは `label do text("Query") end` のように 1 行にまとめる。文が複数あるブロックでも、最初の文が同じ行に続き、閉じる `end` の字下げが揃わないことがある。インデントで範囲を決めると、1 行で閉じた `label` の後の `input` をラベルの中とみなして通してしまう。キーワードを数えればこの形でも範囲が決まる。

`finished` はプログラム全体を読んだ後に一度だけ動くので、同じビューのすべてのメソッドと、親とモジュールが見える。仕様の「同じビュー」に合う。メソッド本体は展開前の整形済み文字列で受け取れるので、`html` の `title` 個数検査と同じ字句走査の方式が使える。仕様は `input` を例外なく検査すると書いているので、送信用の `input` は外さず、`button` を勧める。`aria-labelledby` は `aria-label` と同じくアクセシブルな名前を与える。hidden を除外しないと、CSRF のフィールドを書けない。

# 破棄した案

- インデントで `label` ブロックの範囲を決める（1 行で閉じるブロックの後の `input` を通してしまう）
- メソッドごとに検査する（当初の決定）。別メソッドのラベルを数えず、include したモジュールも見えない
- `html` マクロのブロックだけを走査する（フラグメントとヘルパーメソッドが漏れる）
- `label` ブロックのマクロで中の `input` を書き換える
- `submit`、`reset`、`button`、`image` の `input` を検査から外す（仕様にない例外になる）
- 呼び出し元の `label` ブロックの中で呼ばれたヘルパーの `input` を、ラップされたものとみなす（呼び出しの流れを追う必要があり、字句走査では決まらない）
