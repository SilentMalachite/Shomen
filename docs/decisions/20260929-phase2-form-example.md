# 状況

フェーズ 2 の受入は、フォームを 1 つ持つ例が、送信後に値を表示し直すことである。AGENTS.md の検証コマンドは `examples/hello` だけを走らせる。

当初は、名前が正しければ 303 で空のフォーム `/greeting` に戻していた。最終レビューで、例を動かした人には「Save」が何もしなかったように見えると指摘された。

# 決定

`examples/hello` に `Greeting::Edit`（`GET /greeting`）、`Greeting::Update`（`POST /greeting`）、`Greeting::Show`（`GET /greeting/:name`）を置く。前後の空白を除いた名前が 2 文字未満なら、送った値を入れたまま 422 でフォームを描き直す。名前に `/`、`?`、`#` があるとき、または名前が `..` のときも、同じく 422 で描き直す。それ以外は 303 で `Greeting::Show.path(name: name)` に移り、`Hello, <name>` とフォームへのリンクを表示する。

# 理由

例を増やさずに、既存の検証コマンドで受入を確かめられる。値の表示し直しは 422 の描き直しで確かめられる。成功後に保存した名前が見えるので、送信の結果がわかる。POST の後は 303 で GET に移るので、再読み込みしても再送信にならない。path helper は `/`、`?`、`#` を含む値と、`.`、`..` を拒否するので、送る前に検証で止める。`.` は 2 文字未満の検証で止まる。

# 破棄した案

- `examples/form` を新しく作る
- 成功時の値をセッションに入れて表示する（ルートが Session を読めない）
- 成功時に 303 で空のフォームに戻す（当初の決定。送信の結果が見えない）
- 成功時に POST の応答として 200 で結果を描く（再読み込みで再送信になる）
