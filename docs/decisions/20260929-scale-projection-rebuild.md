# 状況

フェーズ 7 では、プロジェクションの行を DB の表に置ける。表の形は、画面の要求に合わせて変わっていく。Rails はマイグレーションで表をその場で変える。

# 決定

表に置いたプロジェクションの形を変えるときは、その場でマイグレーションしない。新しい名前のプロジェクションを `id` 1 から作り、追いついたら読み先を切り替え、古い表を消す。

# 理由

リードモデルはイベントから作り直せるので、表を直す必要が無い。作り直しの間も古い表で読めるので、止めずに切り替えられる。その場で変える方法は、データの変換を書き、失敗したときの戻し方も考える必要がある。

# 破棄した案

- Rails と同じく、表をその場でマイグレーションする
- 同じ名前のまま表を消して作り直す（作り直しの間、読めなくなる）
