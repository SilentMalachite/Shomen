# 状況

`Shomen::Response` のヘッダは `HTTP::Headers` である。サーバは転送時に、複数値を `", "` で 1 本のヘッダへ結合していた。`Set-Cookie` はカンマ結合できない。

# 決定

ルートが付けたヘッダは、値の配列のまま `HTTP::Server::Response` へ代入する。結合しない。セキュリティヘッダ 3 つは、その後にサーバの値で上書きする。

# 理由

`HTTP::Headers` は配列を複数のヘッダ行として送る。カンマ結合は `Set-Cookie` を 1 つのクッキーとして壊す。フェーズ 2 のセッションクッキーより前に、フェーズ 1 の転送を直す。

# 破棄した案

- 複数値をカンマで結合したままにする
- `Set-Cookie` だけ特別扱いする
