# 状況

リポジトリに CI が無く、PR にチェックが付かなかった。Postgres の spec は `SHOMEN_SPEC_POSTGRES` が無いと pending になり、ブラウザの spec は Chrome が無いと走らない。

# 決定

- GitHub Actions の `.github/workflows/ci.yml` を 1 つ置く。`main` への push と、すべての pull request で走る
- `ubuntu-24.04` で、Crystal は `crystal-lang/install-crystal` の latest を入れる
- サービスコンテナの `postgres:17` を立て、`SHOMEN_SPEC_POSTGRES=postgres://postgres:postgres@localhost:5432/postgres` で Postgres の spec も走らせる
- ブラウザの spec は、ランナーに入っている `google-chrome` で走らせる。Ubuntu 24.04 は非特権ユーザー名前空間を AppArmor で止めていて Chrome のサンドボックスが起動しないので、`kernel.apparmor_restrict_unprivileged_userns=0` にする
- 手順は `AGENTS.md` の検証と同じにし、先頭に `crystal tool format --check` を足す: `crystal build src/shomen.cr --error-trace`、`crystal spec`、`examples/hello` の `shards install` と `crystal spec`

# 理由

フェーズ 6 の受入は Postgres を設定した状態で確かめる（`20260929-phase6-postgres-spec.md`）。CI で毎回それを走らせれば、手元に Postgres が無くても受入を確かめられる。

# 破棄した案

- Chrome に `--no-sandbox` を付ける: spec のコードを CI のために変えることになる
- Crystal 1.20.0 との行列: 今回は求められていない。必要になったら足す
