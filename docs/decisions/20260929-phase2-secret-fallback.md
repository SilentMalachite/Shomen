# 状況

仕様 6 は、署名の鍵を環境変数 `SHOMEN_SECRET` にしている。未設定のときの動きは書いていない。フェーズ 1 の受入「`examples/hello` を `crystal run` すると HTML が返る」は、環境変数なしで満たしている。

# 決定

`SHOMEN_SECRET` が未設定か空文字のときは、プロセスごとに一度だけ `Random::Secure.hex(32)` で鍵を作り、STDERR に 1 行の警告を出す。`Shomen::Server.new(secret:)` で鍵を直接渡すこともできる。

# 理由

必須にすると、フェーズ 1 の受入が環境変数なしでは通らなくなる。ランダムな鍵は再起動で変わるので、それまでのセッションと CSRF トークンは使えなくなる。ほかに失うものは無く、再起動後の最初の応答で新しい Cookie が出る。再起動をまたいでセッションを保つには `SHOMEN_SECRET` を設定する。本番での扱いはフェーズ 6 の範囲である。

# 破棄した案

- 未設定なら起動に失敗する
- 固定の開発用の鍵をソースに埋め込む
